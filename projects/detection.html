상위뷰 카메라 기반 포즈 인식 및 ROS2 로봇 자동 안내 시스템

프로젝트 기간: 2024-2025

주요 성과: 실시간 포즈 인식과 기하학적 검증을 통한 오탐 최소화, ROS2 네비게이션 통합

프로젝트 개요

이 프로젝트는 신발 매장의 반무인 자동화를 위해 설계되었습니다. 천장에 설치된 상위뷰(top-view) 카메라로 손님의 몸짓(손 들기)을 감지하면, 로봇이 자동으로 해당 위치로 이동하여 서비스를 제공합니다.

기존 정면뷰 방식과 달리 상위뷰는 전체 공간을 사각지대 없이 관찰할 수 있고, 프라이버시를 보호하면서도 정확한 위치 파악이 가능합니다.

시스템 아키텍처

시스템은 다음과 같은 파이프라인으로 구성되어 있습니다:

  1. 객체 탐지: YOLOv8을 사용하여 실시간으로 피규어를 탐지
  2. 포즈 분류: YOLOv26 포즈 모델로 hands_up / hands_down 분류
  3. 기하학적 검증: Solidity와 ReachRatio를 사용한 이중 검증으로 오탐 제거
  4. 자동 라벨링: SAM3(Segment Anything Model)을 활용한 자동 라벨링
  5. 원근 변환: 단응행렬(Homography Matrix)을 통해 픽셀 좌표를 로봇 맵 좌표로 변환
  6. 로봇 네비게이션: ROS2 Nav2 스택으로 자동 경로 계획 및 이동

주요 기능

1️⃣ 실시간 포즈 인식

YOLOv8 + YOLOv26 조합으로 높은 정확도 달성

상위뷰 영상에서 피규어의 손 위치 변화를 감지하여 hands_up/hands_down 분류

2️⃣ 기하학적 이중 검증

Solidity: 윤곽선의 컴팩트함을 측정하여 진정한 손 모양만 인정

ReachRatio: 팔 길이 대비 손의 도달 거리로 신체 일부가 아닌 손만 확인

이 두 기하학적 특성으로 오탐을 99% 이상 제거

3️⃣ SAM3 자동 라벨링

Segment Anything Model을 활용하여 대규모 데이터셋을 자동으로 라벨링

수동 라벨링 시간을 90% 이상 단축

4️⃣ 원근 변환 및 좌표 매핑

카메라 공간의 픽셀 좌표를 단응행렬(Homography Matrix)을 통해

로봇의 절대 좌표계(미터 단위)로 정확하게 변환

이를 통해 로봇이 정확한 위치로 이동 가능

5️⃣ ROS2 네비게이션 통합

ROS2 Topic 기반으로 실시간 목표 좌표 발행

Nav2 스택이 동적 장애물 회피 및 최적 경로 계획 수행

demo_ros.py가 전체 파이프라인의 통합 실행 파일

학습 및 평가 결과

정확도: 상위뷰 환경에서 98.5% 정확도 달성

처리 속도: GPU 기준 30 FPS 이상의 실시간 처리

오탐율: 기하학적 이중 검증으로 1% 이하로 감소

기술적 도전과 해결

문제: 단순 YOLO 모델만으로는 10% 이상의 오탐 발생

해결: Solidity와 ReachRatio를 기반으로 한 기하학적 이중 검증 추가

문제: 수동 라벨링으로 인한 높은 비용과 시간

해결: SAM3 모델을 활용한 자동 라벨링 시스템 구축

문제: 카메라 좌표에서 로봇 맵 좌표로의 정확한 변환

해결: 단응행렬을 이용한 2D 원근 변환

향후 개선 계획

  • 다중 카메라를 활용한 3D 포즈 인식으로 확장
  • 깊이 센서(Depth Camera) 통합으로 더욱 정확한 거리 측정
  • 다양한 환경(조명, 배경)에 대한 강건성 향상
  • 멀티로봇 협력 시스템으로 확장

결론

이 프로젝트는 최신 AI 기술과 로봇공학을 결합하여 실제 상용 시스템에 적용 가능한 지능형 로봇 안내 시스템을 구현했습니다. 기하학적 검증과 자동 라벨링을 통해 높은 정확도를 달성했으며, ROS2 통합으로 실제 로봇 플랫폼과의 호환성을 보장합니다.
